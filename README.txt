VOLOX BATTLE — POLISHED ALL-IN-ONE

One main project. This is the build to keep improving.

Included:
- Third-person 3D gameplay
- Procedural humanoid character
- Run animation
- Rifle model
- Shooting + crosshair
- Ammo and reload
- HP + armor
- Enemy patrol/chase/attack/death
- 14 enemies
- Cover objects
- Ammo/loot pickups
- Shrinking safe zone
- Android joystick
- Touch camera
- Sprint/jump/reload/fire controls
- PC fallback
- Android export preset

This is an original battle-royale prototype, inspired by the genre rather than copying Free Fire assets or UI.

Important:
A real commercial battle royale with 100 online players requires networking/backend infrastructure, server authority, anti-cheat, matchmaking, production 3D assets, animation, audio, and extensive optimization/testing. This project is the gameplay foundation.

APK:
See BUILD_ANDROID.txt. The provided environment cannot compile an APK because Godot + Android SDK are not installed.
